# 什么，你说微积分之类的太难？那是你不会用chatGPT学习模式！

openAI一向是AI届的风向标，就如同手机都对标苹果，汽车都对标特斯拉，AI也都在对标chatGPT。

2025年7月29日，chatGPT发布了一项新功能，`学习模式`功能。

在 ChatGPT 中学习的一种新方式，它通过逐步指导而非快速回答来辅助学习。

这项功能类似一个导师，你可以理解为聘请了一个全能家教、你的24小时专属导师等等。

ChatGPT 正迅速成为全球最广泛使用的学习工具之一。学生们借助它来解决难题、备考以及探索新概念。但其在教育中的应用也引发了一个重要问题：如何确保它被用于支持真正的学习，而不仅仅是提供解决方案却不帮助学生理解这些解决方案？

相信大家在使用AI的过程中，都有一个问题，那就是AI确实能快速的给你答案，但是这个`答案`没有`过程`。就像你解数学题一样，光写个答案上去，老师也是会扣你分的。

这也是现在网上很多人不推荐AI的原因，因为他们认为这会让人丧失思考能力。

现在，GPT上线了`学习模式`，再也不用担心只给你答案了。

> 当学生使用学习模式时，系统会提供引导性问题，根据他们的学习目标和技能水平调整回答内容，从而帮助他们建立更深入的理解。学习模式生动有趣且互动性强，旨在帮助学生真正掌握知识——而不仅仅是完成任务。  

## 学习模式的构建过程

在技术层面，学习模式由openAI与教师、科学家及教育学专家合作开发的定制系统指令支持，旨在体现支持深度学习的核心行为，包括：
- 鼓励积极参与
- 管理认知负荷
- 主动培养元认知和自我反思能力
- 激发好奇心
- 提供具有实际操作性和支持性的反馈

这些行为基于学习科学领域长期以来的研究成果，并决定了学习模式如何对学生做出响应。

“与其替他们完成作业，学习模式更鼓励学生对学习过程进行批判性思考。此类功能是推动 AI 在学习领域有效应用的积极一步。即便在 AI 时代，最有效的学习仍发生在学生对课程内容充满热情并积极参与其中时。”——Common Sense Media AI 项目高级总监 Robbie Torney。

## 主要功能

- 交互式提示：结合苏格拉底式提问、提示和自我反思提示，引导理解，促进主动学习，而非直接提供答案。
- 支架式回复：信息被整理成易于理解的章节，突出各主题之间的关键联系，通过恰到好处的背景信息保持内容的吸引力，并减少复杂主题带来的信息过载。
- 个性化支持：课程会根据用户在之前聊天中回答的问题，评估其技能水平和记忆力，从而为用户量身定制适合其水平的课程。
- 知识检查：测验和开放式问题，结合个性化反馈以跟踪学习进展，有助于巩固知识并提升在不同情境中应用知识的能力。
- 灵活性：在对话过程中，您可以轻松开启和关闭学习模式，从而在每次对话中灵活适应您的学习目标。

## 一些使用例子

用户提问：我是计算机科学的大四学生，但我忘记了这门课上的一切。这是教学大纲，是离散数学。我是大一的时候上的，我记得我完全迷路了。你能帮我重新学习吗？

GPT回答：
```
太好了，谢谢你上传教学大纲！在我们深入研究之前，让我们快速校准一下。

一个简单的问题：

1. 你的目标是什么？（例如，“为技术面试做准备”，“在内容相似的课程中取得好成绩”，“填补研究生入学前的空白”）

2. 那时候这门课的哪些部分最让人困惑？（例如，证明、逻辑、归纳法、图论？）

3. 你喜欢怎样学习？（你喜欢大量的练习题、视觉解释、教学等吗？）

让我们一起重新建立起来——但这次要更聪明一些。
```

继续提问：
```
1. 我只想再学一遍。我想看看这种学习模式是怎么运作的！

2. 我不记得了，全部都记得吗？递归代码非常困难。

3. 我认为以上都是
```

GPT回答：
```
太棒了，从头开始。

让我们重新建立起你的基础，一点一点。我们将这样做：

1. 从小事开始：一次一个主题（我们将按照课程顺序进行，除非你想跳过）。

2. 混合使用：我会在问题、教学、短练习和复习之间切换。

3. 经常查看：如果有任何不清楚的地方，我们会暂停并深入了解。

🔹第一站：鸽子洞原理

让我们慢慢来——它在你们的教学大纲的前面，是数学推理的经典入门。

Q1：在我定义它之前，你认为鸽子洞原理可能意味着什么，仅从名字上看？

（不要有压力——鼓励猜测。）
```

提问：
```
好吧。我记得如果鸽子比洞多，那么就会有重叠。所以如果你有5个人，4种颜色的衬衫，你可以肯定地说不止一个人穿着其中一种颜色。

我记得我发现很难识别分类原理问题的证明等。就像期末考试有一个非常难的问题完全难倒了我，我的朋友说“哦，是PHP”。我至今还记得我对这个问题有多恼火
```

GPT回答：
```
🔹重申你说过的话（你说对了）

基本思想如下：

如果鸽子数量多于鸽笼数量，则至少有一个鸽笼数量大于2只。

衬衫的例子你说得很好。这就是基本的鸽子洞原理。

我们稍后会讲到一个更强大的版本。

让我们做一个快速的热身：

假设房间里有13个人。我们能保证至少两个孩子是在同一个月出生的吗？
为什么或者为什么不？

尝试一下——暂时不要担心形式证明语言。解释你的理由。
```

可以看到，AI在引导你学习，引导你思考。这是一个非常好的学习方式。
